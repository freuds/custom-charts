Utiliser ce repo Helm

  1. Ajouter le repo et récupérer son index :

    helm repo add custom-charts https://freuds.github.io/custom-charts
    helm repo update custom-charts

  2. Lister les charts et leurs versions disponibles :

    helm search repo custom-charts --versions

  3. Consulter les valeurs par défaut d'un chart avant de le personnaliser :

    helm show values custom-charts/<chart> > values.yaml

  4. Installer ou mettre à jour un chart avec ses valeurs :

    helm upgrade --install <release> custom-charts/<chart> --version <version> -n <namespace> --create-namespace -f values.yaml
